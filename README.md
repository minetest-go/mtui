# Features

* Account/Password management
* Remote console (chat, lua-injection)
* Chat console
* World status
* Skin management
* Mail management
* XBan management
* Mediaserver (remote_media)
* Event logging
* Mod/game/texturepack configuration and updates (git)
* File browser
* Luanti config management

# Dev

```sh
docker compose up
```
